# Tock Studio

_Tock Studio_ regroupe les interfaces utilisateur, techniques et métier des bots : configurer les fonctionnalités
[Gen AI](../gen-ai/index.md), écrire les stories et les réponses qui encadrent les réponses générées, entraîner le
modèle NLU qui choisit entre les deux, suivre les conversations et mesurer leur qualité.

Les menus _Gen AI_ (RAG, base vectorielle, playground, observabilité...) et le menu _Answers Quality_ sont décrits dans
la section [Gen AI](../gen-ai/index.md). Cette section décrit les autres menus :

* [Le _Dashboard_](dashboard.md) et l'[interface générale](general.md)
* Stories et réponses :
    * [Le menu _Stories & Answers_](stories-and-answers.md)
    * [Les menus _FAQ_](faq.md)
    * [Créer un bot multilingue](i18n.md)
* _Language Understanding_, le modèle NLU qui oriente chaque phrase vers une story, une FAQ ou le RAG
  (voir [Comment le bot répond](../gen-ai/how-it-works.md)) :
    * [Le menu _Language Understanding_](nlu.md)
    * [Intentions](intents.md)
    * [Entités](entities.md)
    * [Construire un modèle conversationnel](build-model.md)
    * [Le menu _Model Quality_](model-quality.md)
    * [Restreindre le périmètre des intentions](intents-restrictions.md)
* [Le menu _Test_](test.md)
* Pilotage :
    * [Le menu _Analytics_](analytics.md)
    * [Le menu _Custom Metrics_](custom-metrics.md)
* Administration :
    * [Le menu _Settings_](configuration.md)
    * [L'écran _Synchronization_](synchronization.md)

La configuration des canaux est décrite dans la section [Canaux](../channels/index.md).
