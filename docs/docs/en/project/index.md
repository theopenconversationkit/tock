# The Tock project

Tock (_The Open Conversation Kit_) is an open source project, under the
[Apache 2 license](https://github.com/theopenconversationkit/tock/blob/master/LICENSE).

* [Why Tock](why.md): the history and the principles of the project.
* [User Showcase](showcase.md): the organizations and the bots that use Tock.
* [Community](community.md): how to get help and talk with the Tock users and contributors.
* [Contributing](contribute.md): building Tock from the sources and proposing changes, to the code or to this documentation.
* [Resources](resources.md): presentations, videos and articles about Tock.
* [Changelog](changelog.md): the main changes of each release.
