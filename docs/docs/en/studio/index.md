# Tock Studio

_Tock Studio_ brings together the user, technical and business interfaces of the bots: configure the
[Gen AI](../gen-ai/index.md) features, write the stories and answers that frame the generated answers,
train the NLU model that decides between them, follow the conversations and measure their quality.

The _Gen AI_ menus (RAG, vector store, playground, observability...) and the _Answers Quality_ menu are described in the
[Gen AI](../gen-ai/index.md) section. This section describes the other menus:

* [The _Dashboard_](dashboard.md) and the [general interface](general.md)
* Stories and answers:
    * [The _Stories & Answers_ menu](stories-and-answers.md)
    * [The _FAQ_ menus](faq.md)
    * [Building a multilingual bot](i18n.md)
* _Language Understanding_, the NLU model that routes each sentence to a story, an FAQ or the RAG
  (see [How the bot answers](../gen-ai/how-it-works.md)):
    * [The _Language Understanding_ menu](nlu.md)
    * [Intents](intents.md)
    * [Entities](entities.md)
    * [Building a conversational model](build-model.md)
    * [The _Model Quality_ menu](model-quality.md)
    * [Restricting the scope of intents](intents-restrictions.md)
* [The _Test_ menu](test.md)
* Monitoring:
    * [The _Analytics_ menu](analytics.md)
    * [The _Custom Metrics_ menu](custom-metrics.md)
* Administration:
    * [The _Settings_ menu](configuration.md)
    * [The _Synchronization_ screen](synchronization.md)

The configuration of channels is described in the [Channels](../channels/index.md) section.
